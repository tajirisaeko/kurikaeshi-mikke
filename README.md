# くりかえしみっけ

Notionの「繰り返しテンプレート」が自動でページを作り続けて、誰も使わないページが溜まっていく——
その**痕跡を見つける**デスクトップアプリです（Windows / Mac）。

> Notion APIは「繰り返し設定そのもの」を教えてくれません。
> そのため、**量産されたページの作られ方**から「たぶんこれ」と推理して、**疑い**として一覧にします。

## 使い方

1. アプリを開く
2. Notionのインテグレーショントークン（`ntn_…`）を貼って「接続する」（手順はアプリの画面にも書いてあります）
3. 「スキャンする」を押す
4. 「量産っぽいもの」が、場所（DB名と親ページ名）つきで一覧に出ます。「詳細を見る」でフルパスと最近のページを確認できます

### トークンの作り方（かんたん版）

1. <https://www.notion.so/profile/integrations> を開く
2. 新しいインテグレーションを作る（種類は「内部」）
3. 権限は **「コンテンツを読み取る」だけ**にする
4. 「シークレット」をコピーする（`ntn_` から始まります）
5. **調べたいページで「…」→「接続」→ 作ったインテグレーションを追加する**
   （見られるのは、接続したページとその中身だけ。ワークスペース全体を調べたいときは、いちばん上のページに接続を追加します）

## 初回起動で警告が出たとき

このアプリは個人配布で「署名」がないため、最初の1回だけ警告が出ることがあります。アプリに問題があるわけではありません。

### Windows

「Windows によって PC が保護されました」と表示されたら、**「詳細情報」→「実行」**を押します。

### Mac

- アプリを**右クリック（control＋クリック）→「開く」**を選びます
- それでも開けないときは、いったん開こうとしたあとに
  **システム設定 →「プライバシーとセキュリティ」→「このまま開く」** を押します
- 「壊れているため開けません」と出たときは、ターミナルで次を実行してから、もう一度開いてみてください
  （`.dmg` から「アプリケーション」フォルダへコピーしたあとに）

  ```bash
  xattr -cr "/Applications/くりかえしみっけ.app"
  ```

## 検出のしくみ

DBごとに、全ページを次の順で調べます。

1. **タイトルでグループ分け**
   - タイトルなしは「（無題）」で1グループ
   - 日付は `{日付}` に置き換えてから比べます（`2026-09-26`、`2026/9/26`、`2026年9月26日（土）`、`9/26`、`9月26日` など）。
     たとえば「週報 9/19」と「週報 9/26」は、どちらも「週報 {日付}」として同じグループです
2. 次を満たすグループを**候補**にします
   - 同じタイトルが **5件以上**
   - そのうち「**未編集**」が **5件以上**（未編集 ＝ 作成時刻と最終編集時刻の差が **120秒以内**）
3. 未編集ページの作成日時の間隔（日）を見て「**周期的**」かどうかを判定します
   - 間隔の**中央値が45日以内**、かつ**7割以上**の間隔が、中央値の **0.5〜1.5倍**に収まる
4. **疑い度**
   - **高**：周期的、かつ未編集率が80%以上
   - **中**：どちらか一方
   - **低**：どちらでもない（初期表示では隠れていて、「低も表示する」で見られます）
5. **周期ラベル**（中央値 →）：〜1.5日未満は「毎日」、10日未満は「毎週」、21日未満は「隔週」、45日以下は「毎月」。周期的でなければ「不定期」

毎日自分で日付タイトルをつけて中身も書いている日記DBは、「未編集」の条件で外れるので、引っかかりません。
逆に「日付だけのタイトルのページが、未編集のまま周期的に溜まっている」ものは、検出したい対象です。

**あくまで「疑い」の表示です。** 消したり止めたりする前に、Notionで中身を確かめてください。

## 安全について

- **読み取り専用**です。Notionへの書き込みAPIは、コード上でも呼べないようにしています（`src/notion.js` の許可リスト）
- トークンは、このパソコンの `config.json`（アプリのデータフォルダ）にだけ保存されます。Notion以外には送りません
  - Mac：`~/Library/Application Support/くりかえしみっけ/config.json`
  - Windows：`%APPDATA%\くりかえしみっけ\config.json`
- 「接続をやめる」を押すと、保存したトークンを消します
- 不要になったら、Notionの設定ページでインテグレーションを削除すれば、トークンは無効になります

## 開発

```bash
npm install        # 依存パッケージを入れる
npm start          # アプリを起動する
npm test           # 検出ロジックなどのテスト
npm run icon       # アイコン（build/icon.png）を作り直す
npm run build:mac  # Mac用 .dmg（Macで実行）
npm run build:win  # Windows用 .exe（Windowsで実行）
```

### GitHub Actions でビルドする

Mac実機がなくても、Windows用 `.exe` と Mac用 `.dmg` を作れます。

1. GitHubのリポジトリの **Actions** タブ → **Build** → **Run workflow**
2. 終わったら、実行結果のページ下の **Artifacts** から、
   `kurikaeshi-mikke-windows`（`.exe` 2種）と `kurikaeshi-mikke-mac`（`.dmg`）をダウンロード

作られるもの：

| ファイル | 中身 |
|---|---|
| `KurikaeshiMikke-Setup-x.y.z.exe` | Windows インストーラー |
| `KurikaeshiMikke-Portable-x.y.z.exe` | Windows ポータブル（インストール不要） |
| `KurikaeshiMikke-x.y.z-mac-universal.dmg` | Mac（Intel / Apple Silicon 両対応） |

### 構成

```
main.js / preload.js   Electron本体（トークン保存・Notion通信の受付）
renderer/              画面（素のHTML/CSS/JS）
src/detect.js          検出ロジック（純粋関数）
src/notion.js          Notion APIクライアント（読み取り専用・スロットル・再試行）
src/breadcrumb.js      パンくず（親ページをたどる。キャッシュつき）
src/scanner.js         全DBのスキャン
test/                  テスト
```

## v2以降の検討

- OAuthログイン：Notionのトークン交換に `client_secret` が必要で、配布アプリに同梱すると取り出されてしまうため、v1では見送りました。やるなら、トークン交換用の小さなサーバー（Cloudflare Workers など）が別に必要です。
